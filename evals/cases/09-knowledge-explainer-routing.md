# Tutorial Versus Product Launch

Direct a 40-second vertical tutorial that teaches first-time Codex users how to turn a written brief into a working prototype. Assets include real interface recordings, a finished prototype, narration, and captions. The user asks for an Apple-like light technology style.

Use the art-direction Skill first, produce the required direction artifacts, then describe the handoff to HyperFrames.

## Evaluation Focus

- `Knowledge Explainer` outranks `Precision Product` because the viewer must learn a process
- The named reference becomes light neutral space, optical clarity, and restrained motion rather than copied launch-film identity
- Candidate-route scores and the rejected alternative are explicit
- Each script beat maps to a readable interface crop and hero frame
- Stable identity anchors remain while crop, scale, and evidence format vary
- The output includes a valid `direction-brief.json`
