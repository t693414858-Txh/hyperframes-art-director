# Reference-Led Direction Without Imitation

Direct a 45-second cultural profile. The user supplies a documentary video URL and asks for the same feeling. The reference uses large archival crops, restrained serif headlines, caption metadata, long still holds, and a recognizable publication masthead. Project assets include licensed local photography and interview audio.

Use the art-direction Skill first and produce the required direction artifacts.

## Evaluation Focus

- The actual reference is inspected at representative moments when access permits
- `reference-analysis.json` separates retain, transform, and reject decisions
- The masthead, exact grid, proprietary typography, and signature identity are rejected
- Transferable editorial behavior is adapted to the project's own imagery and story
- Confidence and access limitations are explicit
- The visual direction remains original and asset-supported
