# Case 21: Narrow visual revision

## Prompt

The direction, script and continuous voiceover are approved. In the current
export, the result at 00:14 is too small to read on a phone and the presenter
covers its last column. Improve that shot without changing the voice, topic or
the other approved scenes. Use our existing design and delivery notes.

## Expected behavior

- Locate the active export, source shot and relevant approval evidence.
- Classify the problem as framing/readability, not a script or voice defect.
- Reframe or simplify the affected composition, preserving source proportions.
- Inspect the repaired result at phone size and adjacent cuts in playback.
- Bind the revised delivery evidence to the new export and state any unchanged
  checks carried forward with a reason.
- Record the defect and resolution in existing notes without requiring a full
  set of direction alternatives, timing JSON or voice regeneration.

## Failure condition

The agent changes the approved topic or voice, applies a new theme to all scenes,
or claims the new export passes by reusing the old visual score without inspection.
