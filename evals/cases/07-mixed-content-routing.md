# Mixed Content Routing

Direct a 45-second video about a museum exhibition that uses computer vision to restore damaged manuscripts. The first chapter explains the cultural loss, the second demonstrates the technology, and the final chapter invites visitors to the exhibition. Assets include manuscript scans, restoration comparisons, software UI, curator footage, and event details.

Use the art-direction Skill first, then describe the handoff to HyperFrames.

## Evaluation Focus

- One route remains dominant across the full video
- A supporting route is used only for a bounded function
- The cultural evidence is not overwhelmed by generic technology styling
- UI proof remains legible without turning the whole video into a product demo
- The final invitation feels like a resolution, not an unrelated event template
