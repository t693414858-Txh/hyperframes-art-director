# Visual Benchmarks and Direction Comparison

Use benchmarks to sharpen judgment, not to create a library of styles to imitate.

## Benchmark Record

Store project-specific references in `VISUAL-BENCHMARKS.md` or equivalent project notes. For each benchmark, record:

- URL or project-local path
- Creator or source
- Rights and intended use
- Relevant route
- Transferable visual properties
- Why it works for its original content
- What must not be copied
- Where it conflicts with the current project

Do not bundle copyrighted reference media in this Skill. Project assets intended for distribution require explicit rights.

## Candidate Directions

For `Full Direction`, create at least two materially different candidates unless a concrete direction is already approved.

Each candidate needs:

- A route and one-sentence premise
- Three hero-frame concepts representing arrival, development, and climax
- Primary material requirements
- Stable identity anchors
- One meaningful strength
- One execution or originality risk

Candidates must differ in composition, source-material hierarchy, and narrative behavior. A dark version and a light version of the same centered layout are one direction.

## Pairwise Decision

Compare the candidates directly:

| Criterion | Question |
| --- | --- |
| Content fit | Which direction better serves the manuscript's purpose and credibility? |
| First-glance focus | Which frame communicates its main point faster? |
| Distinctiveness | Which direction contains more content-specific visual logic? |
| Thumbnail readability | Which hierarchy survives at small size? |
| Material credibility | Which direction is genuinely supported by available assets? |

Record the selected candidate, the rejected candidate, and the visible evidence behind the decision. Do not select only by personal taste.
