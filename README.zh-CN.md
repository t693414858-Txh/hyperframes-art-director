# HyperFrames Art Director

这是为 HyperFrames 视频提供视觉方向、镜头规划和成片审核的 Codex Skill。视频实现与渲染使用已安装的 HyperFrames 技能。

## 0.11.0 的取舍

多轮剪辑暴露的问题是：规则不断增加，实际缺陷却可能被流程和评分掩盖。这次把主流程压缩为五步，日常修改默认使用简明审核，复杂项目再启用结构化检查。

| 保留 | 删减或调整 |
| --- | --- |
| 根据内容选择风格和制作方式 | 看到科技就套苹果风、看到文化就套报纸风 |
| 项目识别、素材真实性和来源 | 每条视频都强制身份占比和完整评分表 |
| 真实动作、镜头用途、素材去重 | 为了每隔两秒变化而增加无意义点击 |
| 已认可音色、字幕同步、最终文件检查 | 为修画面而重新配音或整片重做 |
| 具体时间点的问题和修复证据 | 每次小改都重复生成多份 JSON |
| 当前项目已确认的字幕和片尾偏好 | 把某个账号、配音引擎的参数当成通用标准 |

## 现在怎么制作

1. 锁定本期主题、观众收益、当前版本和已认可内容。
2. 选择制作形态和视觉方向，核对参考来源。
3. 新方向或反复失败的画面先检查代表性样片，再扩大制作。
4. 按镜头用途剪辑，找到问题原因后修改对应部分。
5. 检查实际导出的文件，说明已解决和仍未解决的问题。

| 制作形态 | 主体素材 | 核心检查 |
| --- | --- | --- |
| 操作教程 | 实际输入、操作、结果和验证 | 因果是否清楚，动作是否真实，结果能否看清 |
| 案例分析 | 相关人物、工作过程与环境，穿插来源 | 论点有依据，镜头与口播相关，节奏和材料有变化 |
| 作品展示 | 已确认作品、细节和对比 | 原作与比例保持准确，观众有时间看清 |
| 故事影片 | 人物行动、反应与后果 | 所承诺的动作在画面中实际发生 |

素材丰富度看工作环节、动作、环境、景别和源片段。同一段素材换裁切不算新素材；有叙事用途的回扣可以保留。已认可运镜后，修改重复和节奏应延续原方向。

## 审核怎么做

默认沿用现有设计稿、镜头表和交付记录，以“时间点、可见问题、原因、修改、验证证据”记录缺陷。审核覆盖主题表达、画面可读性、播放节奏、声音字幕和文件版本。

正式对比、复杂片子、反复未解决的问题或已有自动化流程，可以选用详细方向合同、内容节奏、体验互动和八维评分。原有验证器继续兼容，但不要求每次修改全部运行。具体选择见[审核流程](skills/art-direct-hyperframes/references/review-workflow.md)。

## 时间门槛可以配置

原教程配置仍兼容：0.8 秒结果预览、2.5 秒操作、5 秒证据、8 秒验证、前段状态间隔不超过 2.5 秒，单任务和多步骤分别采用 35/50 秒时长上限。

这些数字是可选制作配置。新项目采用时要说明依据；重要证据需要更长阅读时间，可以在完整计划中加入：

```json
{
  "thresholds": {"meaningful_state_change_gap_seconds_max": 4.5},
  "threshold_rationale": "保留文件名对比画面，让观众能读完修改前后的差异。"
}
```

检查器输出实际使用的阈值，并保留证据和连续操作要求。不能在成片失败后随意放宽数字来声称通过，也不能虚填动作时间。[完整说明](skills/art-direct-hyperframes/references/shortform-retention-standard.md)。

## 安装和调用

在仓库目录中执行：

```bash
cp -R skills/art-direct-hyperframes "${CODEX_HOME:-$HOME/.codex}/skills/"
```

如果没有立即发现技能，刷新或重启 Codex。

```text
使用 $art-direct-hyperframes 修改这条视频。保留已认可的音色和视觉方向，
找出素材重复和节奏问题的原因，修改后检查实际成片，只执行适用的审核。
```
