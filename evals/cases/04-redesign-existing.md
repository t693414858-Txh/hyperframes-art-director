Review an existing 30-second HyperFrames product video. The HTML already passes lint, validation, contrast, and layout inspection. Visually, every scene uses centered cards, blue-purple gradients, upward fades, equal five-second durations, and a different transition effect.

Use the art-direction Skill to review the existing work. Do not rewrite HTML.
